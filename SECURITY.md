# Security Policy

Nukkad Chat Corner is a **static** HTML/CSS/JS page (no backend, auth, or database). Fixes apply to the latest default branch.

## Reporting a vulnerability

Do not open a public issue for security-sensitive reports.

Prefer:

1. **GitHub Security Advisories** on `https://www.github.com/khushalsarode/`, or
2. Contact **`@khushalsarode`** on GitHub

Include steps to reproduce and impact when you can.
